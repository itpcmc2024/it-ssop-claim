SSOP Toolkit V3.0.0

ศูนย์รวมเครื่องมือจัดการไฟล์ส่งเบิกประกันสังคม เลือกประเภทงานที่ต้องการใช้งาน

ข้อมูลประมวลผลในเบราว์เซอร์
เลือกระบบงานประกันสังคม
🔒 แนวทางความเป็นส่วนตัวของข้อมูล

ไฟล์ตอบกลับและไฟล์ส่งเบิกทั้งหมดอ่านและประมวลผลภายในเบราว์เซอร์ ระบบไม่จัดเก็บข้อมูลผู้ป่วยออนไลน์

  • ฐานความรู้ออนไลน์เก็บเฉพาะประเภทการส่งเบิก, Error Code, คำอธิบาย, สาเหตุ และแนวทางแก้
  • ไม่บันทึก HN, PID, Invoice, วันที่รักษา, จำนวนเงิน หรือเนื้อหาไฟล์ตอบกลับ
  • รองรับการค้นหาความรู้จากทุกโมดูลผ่าน SSOP Knowledge Center

อัปโหลด แยกข้อมูล แก้ไข ตรวจสอบ และส่งออกกลับชื่อเดิม

📥 รับไฟล์ตอบกลับ SSOCAC

เลือกไฟล์ตอบกลับ .BIL หรือ .txt ระบบจะอ่านเฉพาะ CheckCode และคำอธิบายเพื่อสร้างฐานความรู้ โดยไม่เก็บข้อมูลผู้ป่วย

🔒 Local Processing
ไฟล์จะถูกอ่านภายในเบราว์เซอร์เท่านั้น ระบบจะไม่นำ HN, เลขบัตรประชาชน, Invoice หรือรายละเอียดผู้ป่วยไปบันทึก
Error Knowledge ที่พบ
Error Codeคำอธิบายจากไฟล์ตอบกลับสาเหตุ/ข้อสังเกตแนวทางแก้ไฟล์ที่เกี่ยวข้องฟิลด์ที่เกี่ยวข้องจำนวนที่พบสถานะฐานข้อมูล
📄

ลากไฟล์ .txt มาวาง หรือเลือกไฟล์

รองรับ BILLTRAN, BILLDISP และ OPServices รูปแบบ Windows-874

เงื่อนไขสำคัญสำหรับโครงการ SSO Cancer Care (SSOCAC)
!
OPServices · PrdSeCode = SSOCACต้องระบุรหัสโครงการในข้อมูลบริการ เพื่อให้ระบบ สกส. จำแนกการเบิกเฉพาะโครงการได้
!
BILLTRAN · MemberNo = Case Numberใช้เลข Case Number ของผู้ป่วยที่ได้รับอนุมัติในระบบ SSO Cancer Care
!
OPServices / OPDx · VerCode = Protocol Codeระบุรหัสโปรโตคอลการรักษามะเร็ง เช่น C0111 ตามการอนุมัติ
!
BillItems / DispensedItems · ClaimCat = OPRใช้กับรายการยาและค่าใช้จ่ายที่สำนักงานประกันสังคมจ่ายเพิ่มในโครงการ
