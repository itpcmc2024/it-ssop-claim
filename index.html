⚙️ จัดการระบบ V4.3.1

จัดการผู้ใช้งาน สิทธิ์ และค่ากำหนดส่วนกลาง

👥 ผู้ใช้งานระบบ
Admin จัดการ User ID, Display Name, Role, สถานะ และรีเซ็ตรหัสผ่าน
User IDDisplay NameEmailRoleหน่วยงานสถานะLogin ล่าสุดดำเนินการ
🛠️ ค่ากำหนดระบบ
ตั้งค่าชื่อระบบ โมดูล ค่าเริ่มต้น และตัวเลือกส่วนกลางโดยไม่แก้โค้ด
🧾 แนวทาง Audit และมาตรฐานโมดูล
Display Name Stamp

ทุกการเพิ่ม แก้ไข นำเข้า ZIP/Excel/Reply และเปลี่ยนสถานะจะประทับชื่อผู้ล็อกอินจาก Display_Name

Role-based Access

ADMIN ใช้ทุกเมนู, USER ใช้งานงานทะเบียนและ Knowledge และ VIEWER ดู/ส่งออกทะเบียนพร้อมใช้ SSO Editor แบบ Local Processing

Shared Authentication

โครงสร้าง Login และ Session ใช้ซ้ำเป็นแม่แบบสำหรับโมดูลต่อไปได้

SSO Editor V4.3.1

อัปโหลด แยกข้อมูล แก้ไข ตรวจสอบ และส่งออกกลับชื่อเดิม

📥 รับไฟล์ตอบกลับ SSOP

เลือกไฟล์ตอบกลับ .ZIP, .BIL หรือ .txt ระบบจะอ่าน CheckCode และคำอธิบายตามประเภทการส่งเบิก โดยไม่เก็บข้อมูลผู้ป่วย

🔒 Local Processing
ไฟล์จะถูกอ่านภายในเบราว์เซอร์เท่านั้น ระบบจะไม่นำ HN, เลขบัตรประชาชน, Invoice หรือรายละเอียดผู้ป่วยไปบันทึก
Error Knowledge ที่พบ
Error Codeคำอธิบายจากไฟล์ตอบกลับสาเหตุ/ข้อสังเกตแนวทางแก้ไฟล์ที่เกี่ยวข้องฟิลด์ที่เกี่ยวข้องจำนวนที่พบสถานะฐานข้อมูล
📄

ลากไฟล์ .ZIP หรือ .txt มาวาง หรือเลือกไฟล์

รองรับ ZIP ที่มี BILLTRAN, BILLDISP, OPServices หรือไฟล์ .txt รูปแบบ Windows-874

เงื่อนไขสำคัญสำหรับโครงการ SSO Cancer Care (SSOCAC)
!
OPServices · PrdSeCode = SSOCACต้องระบุรหัสโครงการในข้อมูลบริการ เพื่อให้ระบบ สกส. จำแนกการเบิกเฉพาะโครงการได้
!
BILLTRAN · MemberNo = Case Numberใช้เลข Case Number ของผู้ป่วยที่ได้รับอนุมัติในระบบ SSO Cancer Care
!
OPServices / OPDx · VerCode = Protocol Codeระบุรหัสโปรโตคอลการรักษามะเร็ง เช่น C0111 ตามการอนุมัติ
!
BillItems / DispensedItems · ClaimCat = OPRใช้กับรายการยาและค่าใช้จ่ายที่สำนักงานประกันสังคมจ่ายเพิ่มในโครงการ
