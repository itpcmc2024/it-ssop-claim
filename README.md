# it-ssop-claim V3.4.8 Stable

ต่อยอดจาก V3.4.7 Stable ที่ผ่านการทดสอบ โดยคงระบบ API และ Workflow เดิมทั้งหมด

## เพิ่มในเวอร์ชันนี้

- รายการผล `ติดแก้ไข (C)` มีปุ่ม `🔧 เริ่มแก้ไข`
- เปลี่ยนสถานะเป็น `รอตรวจสอบ` ทันทีโดยไม่ต้องโหลดใหม่
- คง Latest_Result และ Error Code เดิมไว้เป็นข้อมูลอ้างอิง
- บันทึก Timeline `REWORK_STARTED` พร้อม Error Code
- เมื่อสร้าง ZIP ใหม่ ระบบสร้าง Claim_Attempt ครั้งใหม่ตามกลไกเดิม
- ผล `ผ่าน (A)` ไม่มีปุ่มเริ่มแก้ไข
- เลขเวอร์ชันทุกส่วนเป็น V3.4.8

ไม่ต้อง Run setupDatabase และไม่ต้องเพิ่มชีทหรือคอลัมน์
