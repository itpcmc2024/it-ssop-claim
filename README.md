# it-ssop-claim V3.4.6 Stable

ต่อยอดจาก V3.4.4 Stable โดยคงการเชื่อมต่อ API เดิมทั้งหมด

## เพิ่มในเวอร์ชันนี้
- ปุ่ม `พร้อมส่ง` แสดงเฉพาะรายการสถานะ `รอตรวจสอบ`
- ยืนยันก่อนเปลี่ยนสถานะ
- บันทึก Timeline `READY_TO_SEND`
- รักษา Work Order No. และข้อมูลเดิมทั้งหมด
- การ์ดพร้อมส่งนับสถานะ `พร้อมส่ง`

ไม่ต้อง Run setupDatabase


## แก้ไขใน V3.4.6 Stable
- แก้ชื่อฟังก์ชันรีเฟรชทะเบียนหลังเปิด/สร้าง ZIP จาก `applyRegistryFilters` เป็น `applyRegistryFilter`
- สถานะเปลี่ยนเป็น `รอตรวจสอบ` และแสดงบนหน้าจอทันทีโดยไม่ต้องกดโหลดข้อมูลใหม่
- ล้างช่องค้นหาเมื่อกดโหลดข้อมูล
- ป้องกัน Browser/Password Manager เติมชื่อผู้ใช้ เช่น `admin1` ลงช่องค้นหา
